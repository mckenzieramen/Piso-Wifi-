PISO WIFI BUILD v73 — CUSTOMER LOGOUT / CLIENT-LOGIN ROUTE FIX

ROOT CAUSE:
The customer logout path navigated to /client-login.html while Cloudflare Pages clean-URL routing was also handling /client-login. The deployed route could enter a redirect loop.

CHANGES:
- Removed explicit /client-login -> /client-login.html redirect entries from _redirects.
- Kept /client-login.html as the canonical static page that Cloudflare Pages clean URLs can serve as /client-login.
- Customer logout now completes Firebase signOut before navigating to /client-login?loggedOut=1.
- Customer login page now gates stale Firebase auth callbacks during logout until signed-out state is confirmed.
- Cleaned the loggedOut query from browser history after sign-out confirmation.
- Bumped customer login/dashboard cache-busters to v73.

PRESERVED:
- Existing Admin features and routes.
- Customer support reopen flow.
- Customer password setup and recovery flows.
- Firestore rules, Apps Script, data, and design.
