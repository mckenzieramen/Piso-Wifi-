PISO WIFI — PASSWORD RESET EMAIL HTML FIX v47

WHAT CHANGED
- The existing working Firebase password-reset email flow is preserved.
- The password-reset template now uses Firebase's correct %LINK% placeholder.
- A one-time Apps Script setup file was added:
  SET-FIREBASE-PASSWORD-RESET-EMAIL-HTML.gs
- The setup changes Firebase Authentication's reset-password email body format to HTML
  and installs the PISO WIFI branded HTML template.

ONE-TIME SETUP
1. Open the EXISTING PISO WIFI Google Apps Script project that already sends your emails.
2. Add/copy the contents of:
   SET-FIREBASE-PASSWORD-RESET-EMAIL-HTML.gs
3. Save.
4. Run:
   setupFirebasePasswordResetHtmlEmail
5. Approve the Google authorization if prompted.
6. After it finishes successfully, test Forgot Password from:
   https://piso-wifi.pages.dev/

IMPORTANT
- Do NOT change the client login flow.
- Do NOT deploy Firebase Cloud Functions.
- Do NOT change Firestore Rules for this HTML-only fix.
- The existing Firebase sendPasswordResetEmail() remains the email sender.
- The reset link still goes through the existing PISO WIFI reset-password page/action flow.
