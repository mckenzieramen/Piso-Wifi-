Connect · Earn · Grow Together

IMPORTANT IMPLEMENTATION NOTE
The password-reset email itself is generated and delivered by Firebase Authentication when the website calls sendPasswordResetEmail(). Firebase documents that these are template-based emails and that the project's Authentication email template can be customized in the Firebase Console. Fully custom HTML email delivery requires a server-side email flow (for example, generating the reset link with the Admin SDK and sending it through an email service). This project remains on the current client-side Firebase reset-email flow and does not add Cloud Functions or paid infrastructure.
