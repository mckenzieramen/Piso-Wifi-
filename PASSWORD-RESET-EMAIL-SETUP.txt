PISO WIFI — PASSWORD RESET EMAIL

The customer-facing password recovery flow uses the custom PISO WIFI HTML email mailer.

The browser calls the Firebase callable sendCustomPasswordReset. Firebase Admin generates the one-time password-reset action code, converts it to the custom /reset-password.html URL, and sends that URL to the existing Google Apps Script mailer.

The default Firebase Authentication reset email is NOT used by the customer recovery flow.

Required deployment:
- Deploy functions:clientLogin and functions:sendCustomPasswordReset.
- Upload the website files to Cloudflare Pages.
- Keep the existing Apps Script password-reset Web App deployed.

The reset page remains /reset-password.html and consumes the Firebase action code to set the new password.
