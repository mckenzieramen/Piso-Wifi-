PISO WIFI — PASSWORD RESET EMAIL

The customer Forgot Password flow now uses the PISO WIFI custom HTML email path.

Flow:
Customer -> Client ID + registered Gmail -> Firebase callable sendCustomPasswordReset -> Firebase Admin reset action code -> Google Apps Script MailApp.htmlBody -> PISO WIFI HTML email -> /reset-password.html.

The browser must NOT call sendPasswordResetEmail(), because that uses Firebase's default email renderer.

See CUSTOM-HTML-EMAIL-DEPLOYMENT.txt for deployment order.
