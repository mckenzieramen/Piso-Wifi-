PISO WIFI ADMIN DASHBOARD LOADING FIX
Observed: the page stays on "Checking authentication..." indefinitely.
Source-level cause found: initialization waits for auth.authStateReady() before registering onAuthStateChanged(). If authStateReady never settles in the current browser/network state, the listener that would resolve login is never registered and the loading screen stays forever.
Fix:
- Register onAuthStateChanged immediately.
- Add a 12-second timeout that shows a helpful error instead of an infinite spinner.
- Remove the unnecessary "Re-login Now" sidebar button and its JavaScript handler; keep the normal Logout button.
- Bump dashboard.js cache query.

Deploy matching paths only:
- admin/dashboard.html
- js/dashboard.js

This source patch is not deployed to Cloudflare Pages from this environment. If the error UI appears after deployment, it should show a real error instead of spinning forever; use that message to diagnose Firebase/network/rules.
