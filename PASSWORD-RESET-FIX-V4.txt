PISO WIFI PASSWORD RESET FIX v4
2026-09-25 15:57

Root cause fixed:
The customer recovery request was being created with status "pending", while Firestore rules only permitted "email_sent". The request therefore failed before the email flow could run.

The new flow creates a valid pending request, calls the Firebase Admin SDK password-reset generator, sends the custom HTML email through Google Apps Script, and records the email-sent state.
