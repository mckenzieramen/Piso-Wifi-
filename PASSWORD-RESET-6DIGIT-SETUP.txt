PISO WIFI — 6-DIGIT PASSWORD RECOVERY

WHAT CHANGED
- Forgot Password now uses a 6-digit verification code sent by the existing Google Apps Script MailApp/Gmail flow.
- Code expires after 10 minutes and is one-time use.
- Maximum 5 incorrect attempts per issued code.
- After successful verification, the 6-digit code becomes the customer's temporary Firebase password.
- The existing first-login Change Password flow remains unchanged and forces the customer to create a private password after logging in.
- Existing reset-link mailer code remains available; this does not remove it.

FILES
1. js/client-login.js — new 6-digit recovery UI/flow.
2. functions/api/password-reset-code.js — secure Firebase password update bridge.
3. PISO-WIFI-APPS-SCRIPT-MERGED-6DIGIT.gs — complete Apps Script source with the 6-digit flow merged into the existing Apps Script.

CLOUDFLARE
The new Pages Function expects the existing secret as the Cloudflare Pages environment variable:
PASSWORD_RESET_MAILER_SECRET
It must match the value already used by the PISO WIFI Apps Script reset mailer.
No secret is placed in the client-side JavaScript.

APPS SCRIPT
Deploy the included PISO-WIFI-APPS-SCRIPT-MERGED-6DIGIT.gs as the current Apps Script Web App version using the same /exec URL already configured by the site.

CUSTOMER FLOW
Forgot Password → Client ID + registered Gmail → 6-digit code by Gmail → Verify Code → code becomes temporary password → return to Login → log in with username + 6-digit code → existing first-login Change Password appears.

SAFE-EDIT NOTE
No Admin dashboard, customer dashboard, login design, first-login password-change behavior, or other baseline feature was intentionally changed.
