PISO WIFI — CUSTOMER FIRST LOGIN FIX v68

Root cause confirmed from live error:
auth/requires-recent-login was thrown by updatePassword() even after reauthentication.

Targeted fix:
- Removed the fragile updatePassword() path from first-login password setup.
- Freshly signs in with the temporary password.
- Uses Firebase Identity Toolkit accounts:update with the fresh ID token to set the new password.
- Signs in again with the new password to refresh the client session.
- Only then clears units/{unitId}.forcePasswordChange and records passwordChangedAt.
- Keeps the requested success message: "Congratulations! You can now use your PISO WIFI portal."
- No Firestore Rules changes.
- No Admin flow changes.
- No Apps Script changes.
