PASSWORD RECOVERY ROOT-CAUSE FIX — 2026-10-06

The browser-to-Cloudflare-to-Apps-Script connection is working.
The remaining error was server-side customer lookup: the old backend required Client ID + registered Gmail to already exist in the Google Sheet mirror.

This version keeps the Sheet mirror as a first lookup, then falls back to the existing Firestore units collection when the Sheet is empty.

It also uses the Firebase Authentication UID/auth email stored on the customer unit instead of incorrectly looking up Firebase Authentication by the customer's registered Gmail.

No existing Admin login UI or website Firebase configuration is changed by this recovery fix.
