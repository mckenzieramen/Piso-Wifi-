PISO WIFI ADMIN PATCH
1) Removes the unnecessary "Re-login Now" button from the Admin sidebar. Normal Logout remains.
2) The screenshot message "Permanent deletion endpoint is not configured yet" means the Cloudflare Pages Function is present in the front end, but Cloudflare does not have the required server-side secrets configured. This is not a password issue and cannot be solved by changing the button alone.

To enable permanent deletion, configure these in Cloudflare Pages > Settings > Environment variables:
- FIREBASE_PROJECT_ID = piso-wifi-f2b5c
- FIREBASE_API_KEY = existing Web API key from js/firebase-config.js
- FIREBASE_SERVICE_ACCOUNT_JSON = full JSON key for a dedicated Google service account with appropriate Firebase Authentication deletion and Firestore profile permissions. Store as a secret, never in public code.
Deploy the functions/api/admin/delete-cashier.js Pages Function together with js/dashboard.js and admin/dashboard.html. Verify the endpoint exists at /api/admin/delete-cashier after deployment. Test on a disposable Cashier account first.

Do not remove sales/history records. Permanent Auth deletion needs a trusted server-side function.
This patch is not deployed live from this environment.
