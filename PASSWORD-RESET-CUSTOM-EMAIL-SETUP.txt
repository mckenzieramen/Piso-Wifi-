PISO WIFI — CUSTOM PASSWORD RESET EMAIL SETUP

THIS VERSION CHANGES THE FORGOT PASSWORD FLOW

The Customer Login no longer calls Firebase's normal sendPasswordResetEmail().
Instead:

1. Customer enters Client ID + registered Gmail.
2. Cloudflare Pages Function verifies the customer record.
3. The server generates a Firebase password-reset action link without sending Firebase's default email.
4. The server sends that secure link to the PISO WIFI Google Apps Script mailer.
5. Google Apps Script sends the branded HTML email through MailApp.
6. The Reset My Password button opens /reset-password.html.
7. The existing reset page verifies the Firebase code and changes the password.

IMPORTANT:
Firebase's normal client-side reset email is intentionally not used because it cannot use arbitrary custom HTML. Firebase documents that fully custom email delivery uses a server-generated action link plus your own email delivery service.

1. Deploy it as a Web app.
2. Execute as: Me
3. Who has access: Anyone

   functions/api/password-reset.js

   with the copied /exec URL.

The secret is already matched between the Apps Script code and the Cloudflare function. Do not change it unless both files are changed together.

EXISTING FIREBASE SERVICE ACCOUNT

The password-reset Cloudflare function uses the same FIREBASE_SERVICE_ACCOUNT_JSON environment secret already required by the project's existing /api/client-login function. Do not put the service-account JSON in frontend files.

DO NOT PASTE THE HTML TEMPLATE INTO FIREBASE CONSOLE.

The HTML is already embedded in the revised Google Apps Script mailer. Gmail will receive it as real HTML, not as raw <html> text.
