PISO WIFI — CUSTOM PASSWORD RESET EMAIL V47

This build restores the intended custom HTML password-reset email flow.

Flow:
Customer Login -> Forgot Password -> sendCustomPasswordReset callable ->
Firebase Admin generates a one-time reset action code -> custom reset URL ->
Apps Script mailer -> PISO WIFI HTML email -> reset-password.html

The browser no longer calls Firebase sendPasswordResetEmail() for this flow.
The default Firebase password-reset email is therefore not used by the customer recovery flow.

Required deployment:
1. Upload this website build to Cloudflare Pages.
2. Run DEPLOY-PASSWORD-RESET-CUSTOM-EMAIL.bat from this build.
3. The existing Apps Script password-reset mailer must remain deployed as a Web App.

No Firestore Rules change is required for the server-side email send because Firebase Admin SDK writes bypass client Firestore rules.

If the email service is unavailable, the Customer Error Monitor will report the exact backend stage instead of claiming success.
