PISO WIFI — FIREBASE PASSWORD RESET EMAIL
==============================================

IMPORTANT:
This project keeps the existing Firebase native password-reset flow.
Do NOT replace sendPasswordResetEmail() with Apps Script or another mailer.

Use the following values in:
Firebase Console
→ Authentication
→ Templates
→ Password reset
→ Edit


EMAIL SUBJECT
-------------
Reset Your PISO WIFI Customer Account Password


EMAIL BODY
----------
Hello,

We received a request to reset the password for your PISO WIFI Customer Account.

To securely create a new password, click the button below:

Reset My Password

If the button is not available, use the password-reset link provided in this email.

For your security:
• This password-reset link is intended only for your account.
• Do not share this link or your new password with anyone.
• PISO WIFI Admin will never ask you to disclose your private password.

If you did not request a password reset, you can safely ignore this email. Your current password will remain unchanged.

If you need assistance with your account, please contact PISO WIFI Support.

Thank you,

PISO WIFI Management System
Connect · Earn · Grow Together


SENDER / BRANDING
-----------------
Sender name:
PISO WIFI Management System

App name:
PISO WIFI


RESET LINK / ACTION URL
----------------------
Keep the existing Firebase password-reset action link.

The project already contains the custom reset page:
https://piso-wifi.pages.dev/reset-password.html

Do not change the working customer login code for this email-template update.


IMPORTANT LIMITATION
--------------------
Firebase's native Authentication email is template-based. The wording, subject,
sender/app branding, and action URL can be customized from Firebase
Authentication → Templates, but arbitrary custom HTML email code is not
delivered through the client-side sendPasswordResetEmail() flow.

The included HTML file in this project is only a visual reference/preview.
The actual delivered email is controlled by Firebase Authentication's template.

-------------

        ↓
