PISO WIFI PASSWORD RESET FIX V7

Root-cause fix:
- The customer browser previously created passwordResetRequests directly in Firestore.
- A Client ID/Gmail mismatch was therefore rejected by Firestore Security Rules as the generic "Missing or insufficient permissions" error.
- V7 moves validation and recovery-request creation to the server-side Cloud Function.
- The browser now receives the actual reason, such as:
  "The registered Gmail does not match CID-002..."
- Existing Firebase Admin SDK reset-link generation and Google Apps Script branded email flow are preserved.

Deploy both the website and Firebase Functions from this project.
