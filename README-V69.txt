BIG GUY'S CARWASH — V69

Baseline: V68

Changes in V69:
- Settings navigation is now Schedules.
- Weekly site scheduling per employee using Site 1 / Site 2 / Site 3 / OFF dropdowns.
- Employee site is schedule-driven by day; no employee-level Edit Site control is used.
- DTR face recognition validates the employee against the site scheduled for the current day.
- Attendance records save both Scheduled Site and Actual Site.
- Employee DTR recent-month history shows Scheduled Site and Actual Site.
- Employee History popup shows Scheduled Site and Actual Site instead of Hours, with horizontal scrolling.
- Current-day employee table displays the employee's scheduled site.
- Existing V67/V68 functionality preserved.
