V69 — Schedule-driven Site Attendance

1. Schedules
   - Renamed Settings navigation to Schedules.
   - Per-employee weekly schedule: Monday-Sunday.
   - Each day supports Site 1, Site 2, Site 3, or OFF.
   - Weekly schedule is saved to the employee record.

2. DTR location enforcement
   - Current-day scheduled site is the source of truth for DTR site validation.
   - Face recognition rejects a matched employee when the device is not at the employee's scheduled site.
   - Time In/Time Out performs the same site validation again before saving attendance.

3. Attendance site history
   - Attendance stores scheduledSiteId and actualSiteId on Time In.
   - DTR recent-month history shows Scheduled Site and Actual Site.
   - Employee History popup shows Scheduled Site and Actual Site instead of Hours.
   - History popup supports horizontal scrolling.

4. Employee setup
   - No Edit Site control is provided in Employees.
   - Employee form directs site assignment to Schedules.

5. Preserved
   - V68 Reports fixes.
   - V67 location/site features.
   - V66 scroll fixes and DTR selection.
   - Existing payroll, absence/excuse, face enrollment, DTR password, mobile UI and other locked functionality.
